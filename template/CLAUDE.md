@AGENTS.md

## Agent skills

### Issue tracker

GitHub issues in the hub `acme/acme-kb` for every repo (always `--repo acme/acme-kb`); status lives in `status:*` labels. See `docs/agents/issue-tracker.md` in acme-kb.

### Triage labels

Default vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), alongside the `status:*` labels. See `docs/agents/triage-labels.md` in acme-kb.

### Domain docs

Single shared context for every repo: `CONTEXT.md` and `docs/adr/` in acme-kb. See `docs/agents/domain.md` in acme-kb.
