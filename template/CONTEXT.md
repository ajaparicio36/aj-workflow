# Acme

One sentence on what the product is and who uses it. This glossary is shared by every repo in the workspace; agents read it before exploring code and use its words.

Add a term when a conversation settles what a word means. Keep each entry to the definition and the synonyms to avoid. Group terms by area.

## Example area

**Order**:
One purchase by one customer, with one or more lines. It is placed once and never edited; a change is a new order that voids the old one.
_Avoid_: Cart (that is the unplaced draft), transaction

**Void**:
Cancelling an order after it was placed. The order stays, flagged, and drops out of every total.
_Avoid_: Delete, refund (a refund returns money; a void says the order never counted)
